# Wygenerowana warstwa prawna

`generated/legal-content.json` jest wersjonowanym snapshotem generowanym z
`kwikiel/fabryka-legal`. Nie należy edytować go ani treści stron prawnych w tej
aplikacji ręcznie.

Lokalna synchronizacja:

```bash
npm run legal:sync
```

W repozytorium centralnym każda zmiana przechodzi walidację metadanych, budowę
snapshotu i automatyczną propozycję aktualizacji w repozytorium Slayera.
